# Домашнее задание 4 - генератор клиентских документов

**Отдельный кейс:** автоматизация отчётности сервисной компании по данным из SQLite. Здесь не сотрудники, а **108 клиентов** с договорами и услугами. 

## Исходные файлы

- `data/clients.db` — готовая SQLite-база;
- `data/clients_seed.sql` — SQL для создания и заполнения таблицы `clients`;
- `prepare_database.py` — восстановление базы из SQL (пересоздаёт учебную таблицу);
- `templates/client_report.docx` — Word-шаблон с переменными и циклом по клиентам.

Поля: `id`, `client_code`, `full_name`, `city`, `service`, `contract_amount`, `email`, `phone`, `contract_date`, `category`.

## Обязательная часть

1. Подключитесь к `clients.db` через `sqlite3` и получите список клиентов.
2. Проверьте `email`, `phone`, `client_code` регулярными выражениями.
3. Сформируйте **с нуля или по своему Excel-шаблону** отчёт `.xlsx` с таблицей клиентов, общей суммой договоров, средним чеком и сводкой по услугам.
4. Выделите некорректные контакты цветом и добавьте хотя бы одну формулу Excel.
5. Заполните `client_report.docx` с помощью `docxtpl` и сохраните готовый Word-отчёт.
6. Не исправляйте сомнительные контакты без подтверждения: отобразите найденные ошибки отдельно.

## Дополнительно, не обязательно

Сгенерируйте отдельный документ Word для каждого клиента или постройте в Excel диаграмму по услугам.

## Контрольные ориентиры

- Клиентов в базе: **108**.
- Некорректных email: **4**; некорректных телефонов: **4**.
- Общая сумма договоров: **8 396 000 ₽**.

## Поля контекста Word-шаблона

- `company_name`, `report_date`, `total_clients`, `total_amount`, `invalid_count`;
- `clients`: список словарей, включая `client_code`, `full_name`, `city`, `service`, `contract_amount_display`.

**Как восстановить данные:** `python prepare_database.py` (нужна только стандартная библиотека Python). Запуск перезаписывает учебную таблицу `clients`.
